# Agent 管理台操作指南

管理台通过浏览器访问，默认地址见 [部署指南](./agent-management-deploy.zh-CN.md)。左侧导航包含 Agents、对话设定、QQ 权限、会话记录、命令模板、工具与资源、模型与凭据、审计。

## 1. 登录

使用部署时 `management:bootstrap` 创建的管理员账号登录。登录后的写操作需要浏览器自动携带的会话与 CSRF 校验；密钥、会话令牌都不会在页面明文展示。

## 2. Agents：创建、编辑与发布

1. 进入 Agents，点击“新建 Agent”填写名称，创建后自动进入详情页。
2. 在“角色与对话”填写角色背景故事，只描述人物的身世、家庭、工作和经历；说话习惯与表达方式放在对话设定。使用选择框按需添加 0–1 对话设定，未选择的项目不会加入 Agent；每项下方展示 0 与 1 的具体行为说明，也可以移除：
   - 暧昧程度、简短程度、温暖程度、幽默程度、正式程度、共情程度、表情包频率为预置项；
   - 可到“对话设定”页新增自定义项（如好奇程度），无需改代码或重新部署；
   - 数值 0 是有效值，表示倾向到端点，不是关闭；未添加的设定不参与指令。
3. 在“回复节奏”配置三个字段：基础等待毫秒、每秒字符数（0 表示只按基础等待）、本轮等待上限。60 字、1500ms、12 字符/秒、上限 12000ms 时约等 6.5 秒再发送。
4. 在“模型”填写 Provider ID、凭据引用与模型名。API Key 在“模型与凭据”录入一次，AES-256-GCM 加密入库；这里仅填写凭据引用，不输入明文 Key。
5. 在“命令”为 Agent 启用命令模板；/help 会按当前用户权限动态列出可用命令，/reset 清除当前上下文。
6. 点击页面右上角“保存并发布”，角色背景、已选对话设定、回复节奏、模型和命令会在一次提交中保存并发布；校验失败时数据库不保存半成品。发布后下一轮对话生效。回滚请使用历史版本。

默认 Agent 的预置角色背景是一位当代家庭主妇林安宁的虚构经历。新导入的默认 Agent 直接使用这段背景；旧导入中仍使用系统通用文案且未编辑过的默认 Agent 会在管理端启动时更新。旧导入中使用自定义背景的 Agent 不自动覆盖，可在详情页点击“填入默认人物背景”查看内容，再点击“保存并发布”应用。

## 3. 对话设定：自定义 0–1 参数

“对话设定”页在卡片上显示设定说明、默认值和 0/1 两端的行为解释；“查看详情”可查看实际保存的 0、0.5、1 锚点，“编辑设定”可修改说明、默认值及锚点，并生成新版本。点击“新增对话设定”会打开弹窗，填写唯一标识、名称、说明、默认值和三个锚点；唯一标识创建后不可更改。旧版导入的七项预置设定会在页面显示补充说明，不会静默修改已发布 Agent 的行为。修改默认值不会覆盖已有 Agent 的取值；停用会立即影响新轮次，恢复后需在 Agent 上重新发布。自定义参数只影响表达，不能注册工具或提升文件权限。

## 4. QQ 权限：白名单、触发与 Agent 绑定

先填写“QQ 账号 ID”（导入后默认 `imported-bot`），页面会展示：

- 群聊规则：群号、是否允许、触发方式（真实 @、开头短语、精确短语，可组合）、权限上限、是否引用原消息。
- 私聊规则：好友 QQ、是否允许、Agent 绑定。
- 群内用户规则：作用域格式 `群号:QQ号`，可单独覆盖该用户的 Agent。
- 绑定列表：各作用域使用的 Agent。

绑定只决定角色；白名单与权限由规则控制。下方“路由预览”输入场景、群号/QQ、发言人与消息，会返回是否允许、使用哪个 Agent、命中原因与权限上限，不调用模型。

## 5. 会话记录

按场景、发言人筛选会话，点开会话查看消息时间线（用户消息、机器人回复、发送状态）。操作：

- 清除上下文：只清当前上下文段，历史保留，机器人此后从新段开始。
- 删除历史：删除该会话消息与执行记录，同时开启新的上下文段。

上下文只包含确认送达的成功轮次；发送未知或失败的回答不会进入后续上下文。

## 6. 命令模板

创建三类命令：固定回复（返回管理员文字）、模型任务（模板 + 参数，如翻译）、工作流（最多 5 步无循环，可包含搜索或文本步骤）。命令所需能力在 Agent 工具与权限中校验，未知命令会提示 /help。

## 7. 工具与资源

- 表情包：上传 PNG/JPEG/GIF/WebP（≤2MB），校验真实格式与尺寸；模型只能选择已授权素材 ID，同一轮最多一张，严肃求助/错误告警/审批场景不自动插入。
- 文件写入审批：Agent 准备修改白名单资源后生成差异，管理员批准后执行；审批默认 10 分钟有效，原文件变化后失效。只有 Owner 可批准。
- 新增文件资源：登记预装挂载别名（如 notes），可选操作、大小与每日写入上限；自动写入只应开启给专用低风险目录。

## 8. 模型与凭据

1. 新增 Provider：名称 + HTTPS Base URL（本机模型可填 loopback HTTP；私网/元数据地址被拒绝）。
2. 保存凭据：选择 Provider、用途（模型/搜索）、填写 API Key。
3. 校验：点击“校验”只做本地完整性解密测试，不调用外部服务。

凭据列表不显示明文，也不提供取回接口；更换主密钥后需要重加密。

## 9. 审计

查看后台操作记录（谁在什么时间改了什么配置）。历史查看、导出与删除都留有审计；会话正文不写入普通日志。

## 10. 建议顺序

首次使用建议：登录 → 在“模型与凭据”添加 Provider 与 API Key → 新建/导入 Agent 并发布 → 在“QQ 权限”确认群/私聊白名单与绑定 → 用另一个 QQ 账号发消息测试 → 需要搜索时授予 L1 与搜索凭据 → 需要文件时登记资源并按审批使用。
